## Usage

```tsx
import { DataGrid } from "@/components/data-grid/data-grid"
import { DataGridColumnHeader } from "@/components/data-grid/data-grid-column-header"
import { DataGridPagination } from "@/components/data-grid/data-grid-pagination"
import { DataGridScrollArea } from "@/components/data-grid/data-grid-scroll-area"
import { DataGridTable } from "@/components/data-grid/data-grid-table"
import { useEditableDataGrid } from "@/hooks/use-editable-data-grid"
```

The installable includes the reusable family files, the editable-grid hook, and the supporting `Rating` primitive used by the generated editors.

## Examples

### Feature Toggle Demo

<ComponentPreview name="data-grid-demo" />

Use the switches above the table to turn Excel-like filters, inline editing, row pinning,
row reordering, column pinning, menu-based column reordering, and column drag-and-drop on
or off independently. The demo uses the existing DataGrid filter menus and editing
metadata, along with the Base UI CN table and drag-and-drop primitives.

The rows are provided by a frontend-only data source with a typed query and mutation
contract. Its mock implementation serves the full dataset for TanStack's client-side
filtering, sorting, and pagination. A server-backed implementation can use the same query
contract for server-side filtering, sorting, and pagination without changing the table's
feature controls or column definitions.

## Included Pieces

- `DataGrid`, `DataGridTable`, `DataGridScrollArea`, and `DataGridPagination` for the base shell.
- `DataGridColumnHeader`, facet filters, Excel-style text/number/date filters, visibility, virtual, and drag-and-drop helpers for richer table behavior.
- `DataGridEditableCell`, `DataGridEditDialog`, and `useEditableDataGrid` for inline and dialog editing flows.
